# p15：省电改进候选版（Beta，协议7）

2026-11-01。包含作者新增的共享省电策略，两个型号分别编译，不能互刷。

- 仅省电、电池无线且普通运行状态，主循环主动休息4ms；无输入/原始矩阵变化超过1秒后休息8ms。原始按键变化提前恢复活跃节奏；USB、插线、UART忙、镜像接收与休眠切换不加等待。4/8ms不是精确扫描频率或无线回报率。
- 普通版临时清黑原生71颗键RGB，随后绘制状态/电脑显式灯光；不覆盖RGB持久配置，退出省电后恢复。CU指示灯、灯带和音乐例外保持。
- 省电充电心跳与电量查询合并到15秒；状态变化立即入队。其他模式/其他键盘保留原查询行为。低电量提醒可能晚约一个查询周期。
- 协议仍7；EEPROM/VIA/宏、外置日志与计数分区不变，镜像接收仍仅暂存，不安装。

生产省电/消抖隔离测试CU6660、普通版6857断言，无线队列420项通过；双型号ARM构建和128KiB应用边界检查通过。尚未刷入或验证真实输入延迟、极短按键、充电切换、欠压保护和电池电流，不能宣称续航提升百分比；普通版仍无真机验收。代码许可及来源见仓库README和patches/oem-shared-fixes.patch。
