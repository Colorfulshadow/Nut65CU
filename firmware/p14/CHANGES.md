# p14：镜像接收实验（协议 7）

2026-11-01。此版本只用于后续经确认的接收实验，已做原生故障注入/ASan/模拟测试，并在CU完成受控USB/2.4G接收、暂停后断电恢复。当前作者键盘为p14协议7。两个型号固件不能互刷，普通版没有真机验证。

- C5/70 自定义协议：会话号、请求号回显、manifest、分包去重、每页 CRC/读回、持久 ACK、断点继续、完整 SHA-256 和向量检查。
- 当前程序通过链接脚本限制在内部 Flash 前128 KiB；后120 KiB接收镜像、末8 KiB为32页journal。写原语再次限制地址范围。一次页写后恢复 EFL 启用前的 FHSI 状态；空闲初始化不启动擦写时钟。
- 未改变 EEPROM / VIA / 宏布局，也不移动外置日志或计数分区。
- 修复模组发送超时重复清零重试次数的问题，DIAG尾部增加UART retry/drop/queue-full计数，原前缀兼容。
- **没有安装或从暂存区启动的命令。** 收到/校验成功不代表已经刷入；没有实现独立启动器或安装失败回退。以后引入启动器仍需要另一次USB迁移。
- 设备端仅验证结构/CRC/SHA，不验证作者身份；桌面端对实际发送字节验证作者GPG签名。生产接收源码已在CU/RGB、GCC/MSVC ASan下通过60组模拟，含10,328次重复跨配置故障注入；拒绝CRC合法但READY/VERIFYING进度不完整的记录。

应用上限128 KiB、可接收镜像上限120 KiB。实际擦写可能短暂阻塞输入，尚无输入延迟量化、功耗/保护位/cache表征或编程瞬间断电实测。模拟通过不能证明安全无线升级已可用。

CU实测使用已签名p13样本（74,552B），USB约20s、2.4G从1,024B断点续传约91s到READY，当前应用未改变；用户确认该次输入正常。独立-R、消抖与数据保留通过。仍有无线管理请求约200ms待定位；未做擦写瞬间断电、长期续航或量化输入延迟。不含安装器与失败回退。
