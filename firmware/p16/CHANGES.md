# p16 — 省电模式持续关闭全部灯光（Beta，协议7）

CU与普通版共用同一策略：进入省电立即关闭A8灯珠电源和A9升压电源；状态、连接、Caps、低电量、番茄钟、电脑叠加灯光和音乐律动均不例外。USB插线、开机及唤醒遵循当前模式，不因灯效请求重新供电。省电时忽略音乐灯光启动/校准快捷键，退出恢复原灯光设置。

暂停RGB渲染和驱动发送，退出从完整新帧开始；保留RGB设置及延迟保存。音乐选择B6/B7临时拉低，不改音乐设置。设置清除长按及频率测试计时已移至主循环，关灯时仍可使用。

保留电池无线4/8ms扫描休息、15秒电量/充电查询、最多一分钟的空闲休眠上限。USB/插线、UART忙、镜像接收和休眠切换仍绕过扫描等待；等待间隔不是射频回报率。番茄钟等原有保持唤醒条件不变。

协议7、EEPROM布局、键位宏和日志分区保持。应用Flash仍限制128KiB；镜像暂存不包含无线安装器或失败回退。兼容隙照1.3.6及现有管理协议。

验证：两型号生产省电/消抖代码共14499项断言、RGB任务/发送400轮隔离验证、无线队列420项、ARM ELF边界28项和软件双型号镜像识别50项全部通过。本轮未访问或刷写真机；两型号p16的实际电源引脚、电流、极短按键和休眠唤醒仍待硬件验收，未承诺续航增幅。两型号镜像不能互刷。
