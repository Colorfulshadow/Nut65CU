# p13 开发固件：协议 6

2026-11-01。仅编译，按用户要求未运行测试，未刷入键盘。普通版 NUT65 没有真机验证。不要将编译成功视为验收通过。

- 消抖范围 1–30 ms、默认 8 ms；正常 / 省电共用一个值，游戏独立配置，不再硬编码 1 ms。
- USB、BT1–5、2.4G 和全局共八组，蓝牙槽可通过 USB / 2.4G 提前配置。Fn+D 修改当前槽与当前模式并立即保存；1→8，其余→1。
- 新 HID 命令 0x33 GET / 0x34 SET，成功回复带当前生效值、槽和 32 位请求标记。旧 CU/VIA 布局不变；没有新增 HID 安装器。
- 新 EEPROM 块位于原 CU_EXT 预留区 offset36，18 字节；旧 profile / VIA / 宏 / 全局 EEPROM 版本与地址不变。首次迁移保留旧 Fn+D 的正常值，游戏初值 8。
- 修复外置 Flash 读取 / 写区域范围的 u32 加法溢出。

文件名中的 `nut65cu` 与 `nut65rgb` 是不同型号，固件不能互刷。本目录的 SHA256SUMS 由准备脚本生成，作者签名由用户运行 `app/tools/deliver_p13.ps1 -Sign -Commit` 后生成；旧发布的 p12 与原厂备份不变。
